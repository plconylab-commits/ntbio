## Overview

처방전 PDF 파싱 → 거래명세표 자동 완성 기반 위에 고객 DB, 처방이력, 거래이력·미수금, 인쇄/PDF 버그 수정, 처방전↔거래명세표 대조 검토 기능을 단계적으로 추가한 v1.0 MVP 마일스톤.

바닐라 JS + localStorage 구조를 유지하며 빌드 도구 없이 신규 파일만 추가하는 방식으로 회귀 위험을 최소화했다.

## Milestone Summary

### Key Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| 바닐라 JS + localStorage 유지 | 빌드 도구 없이 바로 실행, 기존 코드 일관성 | ✓ Good — 회귀 없이 11 plans 완성 |
| 평당가: 합계 행에서만 추출 | 복합형 처방전 중간 행은 부분값 | ✓ Good |
| IIFE + window.XXX 네임스페이스 | 모듈 시스템 없이 전역 접근 | ✓ Good — customerDB/customerUI/salesHistoryUI/rxCompare/rxCompareUI 모두 동일 패턴 |
| 발행 시 자동 스냅샷 | 별도 저장 버튼 불필요 | ✓ Good |
| 처방전 비교: 카트 덮어쓰지 않음 | 표시 전용, 실수 방지 | ✓ Good |
