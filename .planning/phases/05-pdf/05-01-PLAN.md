2. **PDF 경로(doPdf) 검증:**
doPdf()는 html2canvas로 #printDoc 전체를 하나의 캔버스로 캡처한 뒤 높이별로 슬라이싱한다. buildPrintDoc이 올바르게 다중 .p-wrap을 생성하면 캔버스도 길어지고, 슬라이싱 로직(line 1627-1637)이 `pageH - 12`mm 단위로 자른다.

문제: 슬라이싱이 .p-wrap 경계를 인식하지 못해 페이지 중간에서 잘릴 수 있다.

수정 — doPdf()에서 html2canvas 캡처를 .p-wrap 단위로 개별 수행:

```javascript
  // 기존 단일 캔버스 방식 대체 — .p-wrap별 개별 캡처
  const wraps = clone.querySelectorAll('.p-wrap');
  const { jsPDF } = window.jspdf;
  const pdf = new jsPDF({ unit:'mm', format:'a4', orientation:'portrait' });
  const pageW = pdf.internal.pageSize.getWidth();
  const pageH = pdf.internal.pageSize.getHeight();
  const imgW = pageW - 12;

  for(let wi=0; wi<wraps.length; wi++){
    if(wi>0) pdf.addPage();
    const wCanvas = await html2canvas(wraps[wi], {
      scale: 2, useCORS: true, backgroundColor: '#ffffff',
      width: 794, windowWidth: 794
    });
    const wImgH = wCanvas.height * imgW / wCanvas.width;
    pdf.addImage(wCanvas.toDataURL('image/jpeg',0.97), 'JPEG', 6, 6, imgW, Math.min(wImgH, pageH-12));
  }
```

이 변경으로 각 .p-wrap(=한 페이지 분량)이 정확히 한 PDF 페이지에 대응된다.
