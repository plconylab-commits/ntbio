## Visual Focal Point

**Initial state (upload zone):** Focal point is the `📂 처방전 PDF 선택` button — centered in modal body, full-width, accent background.

**Results state (after comparison):** Primary visual anchor is the diff table's colored status rows. Attention hierarchy:
1. Red rows (`--red-lt` background, `--red` text) — 한쪽에만 ✗ (unilateral items, highest urgency)
2. Yellow rows (`--yellow` background) — 수량 차이 △ (quantity mismatches)
3. Orange rows (`#FFF3E0` background, `--orange` text) — 미매칭 ? (fuzzy match failures)
4. Summary row (`--g-pale` background, bold 14px) — 평당가 comparison at top of table

Matched rows (일치 ✓) are collapsed by default to keep focus on discrepancies.

## Interaction Contract

### Flow

1. User clicks `🔍 처방전 비교` in toolbar.
2. Modal opens showing upload zone. If cart is empty, show error toast via existing `showToast()` and do NOT open modal.
3. User clicks `📂 처방전 PDF 선택` — triggers hidden file input `rxComparePdfInput`.
4. On file selected: hide upload zone, show loading text `처방전 분석 중...`.
5. Call `parsePdfToJSON()` (reuse from `main.js`) — pass result to comparison logic, do NOT write to cart.
6. On success: replace loading state with summary row + diff table.
7. On parse failure: show error copy, re-show upload zone for retry.
8. User reviews diff table. Matched rows are collapsed by default.
9. User clicks `닫기` to close — cart unchanged.

### States

| State | What is shown |
|-------|---------------|
| Initial (no file) | Upload zone centered in modal body |
| Loading | `처방전 분석 중...` text, upload button disabled |
| Results | Summary row + diff table with status rows; focal point on red/yellow/orange rows |
| All matched | `차이 없음 — 모든 품목이 일치합니다.` message |
| Parse error | Error copy + retry button (re-shows upload zone) |
| Cart empty | `showToast()` error, modal does not open |

### Fuzzy Matching Display

For 미매칭 (?) rows: show both the prescription item name and the closest cart item name side by side in the 품목명 column, separated by ` / ` with the prescription name in `var(--orange)` and cart name in `var(--muted)`. This lets the user visually confirm the mismatch.
