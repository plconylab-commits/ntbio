  <action>
    Create `rxCompareUI.js` as IIFE + `window.RxCompareUI` namespace. The file handles ALL UI: modal creation, file input, loading state, diff table rendering.

    **CRITICAL CONSTRAINTS (from CONTEXT.md):**
    - Per D-03: NEVER modify `cart` — read only
    - Per D-04: Use a separate file input `rxComparePdfInput` — do NOT touch `pdfFileInput`
    - NEVER call `handlePrescriptionUpload()` — it overwrites cart. Call `parsePdfToJSON(file)` directly.

    **Module structure:**

    ```javascript
    (function() {
      'use strict';
      // ... all functions below ...
      window.RxCompareUI = { openCompareModal };
    })();
    ```

    **openCompareModal():**
    1. Check `cart.length > 0` — if empty, call `showToast('카트가 비어있습니다. 거래명세표에 제품을 먼저 추가하세요.', true)` and return (per D-02, Interaction Contract "Cart empty" state)
    2. Remove any existing `#rxCompareOverlay` to prevent duplicates
    3. Create overlay div with id `rxCompareOverlay`, use `position:fixed; inset:0; background:rgba(0,0,0,.48); z-index:9900; display:flex; align-items:center; justify-content:center;`
    4. Inner modal box: `background:#fff; border-radius:14px; width:min(600px,94vw); max-height:90vh; overflow-y:auto;`
    5. Modal header: background `var(--g-dark, #2A8A88)`, white text, title `📊 처방전↔거래명세표 비교`, close button `✕`
    6. Initial state: upload zone centered — heading `처방전 PDF를 선택하세요`, body `비교할 처방전 PDF 파일을 업로드하면 현재 카트와 자동으로 대조합니다.`, button `📂 처방전 PDF 선택` styled like `.btn-import`
    7. Hidden file input: `<input type="file" id="rxComparePdfInput" accept=".pdf" style="display:none">`
    8. Close button and overlay click-outside both call `_closeModal()`

    **_onRxFileSelected(input):**
    1. Get file from input.files[0] — if none, return
    2. Hide upload zone, show loading text `처방전 분석 중...` (per Interaction Contract)
    3. Disable the upload button
    4. `try { const json = await parsePdfToJSON(file); }` — parsePdfToJSON is global from pdfParser.js
    5. If json is null or json.rxRows empty or json.prescriptions empty: show error `처방전 PDF를 읽지 못했습니다. 파일을 확인하고 다시 시도하세요.`, re-show upload zone
    6. On success: call `_showResults(json)`
    7. Reset the file input value so same file can be re-selected

    **_showResults(prescriptionJSON):**
    1. Extract rx items: `const rxItems = RxCompare.extractRxItems(prescriptionJSON)`
    2. Build diff: `const diffRows = RxCompare.buildDiffRows(rxItems, cart)`
    3. Get area from prescriptionJSON.farmInfo.totalArea or from document.getElementById('cArea').value
    4. Calc cart pyeongdanga: `RxCompare.calcCartPricePerPyeong(cart, area)`
    5. Get prescription pyeongdanga: `prescriptionJSON.costData?.unitPricePerPyeong || null`
    6. Replace modal body with summary row + diff table

    **Summary row (D-13):**
    - Format: `처방전 평당가: {X}원  /  카트 공급가 합계 ÷ 면적: {Y}원  /  차이: {±Z}원`
    - If prescription pyeongdanga null: `처방전 평당가: 확인불가`
    - If area missing: `카트 면적 미입력`
    - Background: `var(--g-pale, #E0F5F5)`, border `1px solid var(--border, #B2DFDE)`, font-weight 700

    **Diff table (D-05, D-06):**
    - 6 columns: 상태 (48px), 품목명 (auto flex), 처방 수량 (72px), 카트 수량 (72px), 차이 (64px), 금액 비교 (80px)
    - Row backgrounds per status:
      - `match`: `var(--g-pale, #E0F5F5)`, icon `✓`, text color `var(--muted, #666666)`, CSS class `rxcmp-row-match`, hidden by default
      - `qty-diff`: `#FFF9C4`, icon `△`, text color `#1A1A1A`, CSS class `rxcmp-row-qtydiff`
      - `rx-only`: `#FFEBEE`, icon `✗`, text `처방전에만`, color `#C62828`, CSS class `rxcmp-row-rxonly`
      - `cart-only`: `#FFEBEE`, icon `✗`, text `카트에만`, color `#C62828`, CSS class `rxcmp-row-cartonly`
      - For unmatched (?) rows if any: `#FFF3E0`, icon `?`, text color `#E65100`
    - Match toggle button above table: `일치 항목 보기 ({N}건)` / `일치 항목 숨기기 ({N}건)`
    - If ALL rows are match: show `차이 없음 — 모든 품목이 일치합니다.` instead of table
    - 금액 비교 column: show `cart sp*qty` formatted with comma. Since prescription has no item-level price (D-12), show `—` for prescription side.
    - 차이 column: show `+N` or `-N` for qty-diff, `—` for others
    - 닫기 button at modal bottom

    **Styling:**
    - All styles scoped inside `<style>` block within the overlay innerHTML (same pattern as _openOldInvConfirmModal)
    - Use CSS variables from `:root` where available
    - Table: `border-collapse:collapse; width:100%;`
    - Cells: `padding:6px 8px; border-bottom:1px solid var(--border, #B2DFDE); font-size:14px;`
    - Column headers: `font-size:12px; font-weight:700; background:#f0f0f0;`
    - Min row height: 36px
