**2. 기간 계산 유틸 함수들:**
- `_thisMonthRange()` — 이번 달 시작/종료일 반환 `{from:'YYYY-MM-DD', to:'YYYY-MM-DD'}`
  ```javascript
  var now = new Date();
  var from = new Date(now.getFullYear(), now.getMonth(), 1);
  var to = new Date(now.getFullYear(), now.getMonth() + 1, 0);
  return { from: _dateStr(from), to: _dateStr(to) };
  ```
- `_lastMonthRange()` — 지난 달 시작/종료일 반환
  ```javascript
  var now = new Date();
  var from = new Date(now.getFullYear(), now.getMonth() - 1, 1);
  var to = new Date(now.getFullYear(), now.getMonth(), 0);
  return { from: _dateStr(from), to: _dateStr(to) };
  ```
- `_dateStr(d)` — Date 객체를 'YYYY-MM-DD' 문자열로 변환
  ```javascript
  var y = d.getFullYear();
  var m = ('0' + (d.getMonth() + 1)).slice(-2);
  var dd = ('0' + d.getDate()).slice(-2);
  return y + '-' + m + '-' + dd;
  ```
  NOTE: `toISOString().slice(0,10)` 대신 로컬 시간 기준으로 계산해야 한국 시간대에서 정확함.
