customerUI.js의 `_renderAutocomplete()` 함수 내 DB 고객(fromHistory가 아닌) 항목의 배지 카운트 로직을 수정한다.

**현재 코드 (line ~137):**
```javascript
var count = CustomerDB.countPrescriptions(customer.id);
```

**문제:** `countPrescriptions(customerId)`는 `p.customerId === customerId`로 필터한다. 그러나 Phase 3 이전에 저장된 처방이력은 `customerId: null`이어서 카운트에서 누락된다.

**수정:** id 기반 카운트 대신 이름 기반 검색으로 교체한다.

```javascript
var count = (CustomerDB.searchPrescriptions && customer.name)
  ? CustomerDB.searchPrescriptions({ name: customer.name }).length
  : CustomerDB.countPrescriptions(customer.id);
```

NOTE: `CustomerDB.searchPrescriptions({name})` 는 부분 이름 매칭이므로 동명이인 오탐 가능성이 있다. 그러나 기존 `_updateHistoryBadge`도 동일한 방식을 사용하므로 일관성을 유지한다. 향후 이슈 시 exactName 필터 추가.

  <action>
index.html의 `openAllUnpaid()` 함수 (line ~3120) 내 필터 조건을 수정한다.

**현재 코드:**
```javascript
const unpaid=history.filter(h=>{
  if(h.deleted)return false;
  const paid=(h.payments||[]).filter(p=>!p.cancelled).reduce((s,p)=>s+p.amount,0);
  return (h.totals.grandTotal-paid)>0;
});
```

**문제:** `h.deleted` 필드는 `deleteInvoice()`에서 설정되지 않는다. `deleteInvoice()`는 `h.status='삭제됨'`만 설정한다. 따라서 `h.deleted` 체크는 실제로 아무것도 걸러내지 않는다.

**수정:** `h.deleted` 조건을 `h.status === '삭제됨'`으로 교체한다.

```javascript
const unpaid=history.filter(h=>{
  if(h.status==='삭제됨')return false;
  const paid=(h.payments||[]).filter(p=>!p.cancelled).reduce((s,p)=>s+p.amount,0);
  return (h.totals.grandTotal-paid)>0;
});
```

이 한 줄 변경 외에 openAllUnpaid의 다른 코드(지역별 그룹핑, regionTotal 계산, HTML 렌더링)는 모두 유지한다. 지역별 그룹 + 소계 기능은 이미 올바르게 구현되어 있다.

NOTE: addPayment()와 removePayment()에도 `CustomerDB.updateTransaction(inv)` 미러 호출이 이미 추가되어 있는지 확인한다. 없으면 다음 패턴으로 추가:

```javascript
if (typeof CustomerDB !== 'undefined' && CustomerDB.updateTransaction) {
  CustomerDB.updateTransaction(inv);
}
```
